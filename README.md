# Анонимный чат бот Телеграма

Бот для анонимного общения: поиск случайного собеседника, обмен сообщениями (текст/медиа), завершение диалога, базовая модерация.

## Конфигурация

Необходимо создать `.env` файл рядом с `main.go`. Файл должен включать следующие переменные:

    BOT_TOKEN
    DAILY_CHAT_LIMIT
    BAN_THRESHOLD

`BOT_TOKEN` – API токен для авторизации бота. `DAILY_CHAT_LIMIT` – ограничение на количество чатов в сутки при низком рейтинге. `BAN_THRESHOLD` – минимальная граница рейтинга пользователя, при выходе за которую аккаунт банится.

Для запуска минимум нужен `BOT_TOKEN`, остальные переменные имеют заданные в коде дефолтные значения.

## Зависимости

- github.com/go-telegram/bot — клиент для Telegram Bot API (long polling, отправка сообщений)

## Запуск бота
### CLI
Запустить бота из корня проекта:

    go run cmd/api/main.go 

### Docker
Сборка:

    docker build -t anonymous-chat-bot -f deployments/docker/Dockerfile .

Запуск:

    docker run --env-file путь_к_.env anonymous-chat-bot

## Архитектура

Слои:
- handlers — обработка объектов `Update` от сервера Телеграма, связь команд с хэндлерами и отправка сообщений
- services — бизнес-логика бота (поиск собеседника, управление инвариантами, лимиты)
- queue — очередь ожидания
- models — модель пользователя
